# PUBA 720: Applied Research for Public Administrators II

This is a living course website for PUBA 720, a quantitative methods course for Master of Public Administration (MPA) students. The site is built with [Quarto](https://quarto.org/) and published via GitHub Pages.

The site is updated throughout the semester with course content, assignments, announcements, and resources.
